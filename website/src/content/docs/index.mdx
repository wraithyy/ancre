Hyprland-inspired tiling window manager for macOS. No private CGS/SkyLight
window APIs, no SIP tampering — with one documented exception:
`_AXUIElementGetWindow` via `dlsym`, used to get a stable `CGWindowID` from
an `AXUIElement` (the same trick yabai and Amethyst rely on, since there's
no public API for it).

- **Layouts** — dwindle (Hyprland), columns ("scroll"), stack (monocle),
  custom layouts from config templates
- **Workspaces 1–9** across monitors with stable assignment (survives replug)
- **Workspace bar** — window icons, drag&drop, notification badges; positions
  include the menu bar and the notch
- **Hyper key** (CapsLock) for every shortcut + mouse modes (hyper+drag)
- **AI ready** — unix socket + `ancrectl` CLI + built-in MCP server +
  Claude skill

## Quick start

```sh
git clone https://github.com/wraithyy/ancre && cd ancre
swift build -c release
Scripts/bundle.sh
open .build/ancre.app
```

Prefer Homebrew? See [Installation](/ancre/installation/).

Grant **Accessibility** and **Input Monitoring** when asked — details in
[Installation](/ancre/installation/). Then:

```sh
hyper+1..9        # switch workspace     (hyper = CapsLock)
hyper+h/j/k/l     # focus in direction
hyper+t           # scroll layout
ancrectl state    # JSON snapshot of monitors, workspaces, windows
```

Hold hyper for 2 s to see the full [shortcut cheatsheet](/ancre/controls/).

## Known limitations

- Offscreen parking (hiding windows for inactive workspaces) relies on how
  macOS clamps AX window positions near screen edges — behavior that varies
  by macOS version.
- Animations auto-disable for apps whose AX responses are too slow to
  animate smoothly.
- No App Store distribution: ancre needs Accessibility access and remaps
  CapsLock via `hidutil`, both outside the App Store sandbox.
- The app is ad-hoc signed, not notarized — Gatekeeper is satisfied via the
  Homebrew cask (or a manual quarantine clear from source), but there's no
  Apple notarization ticket.
