ancre je **tiling window manager** pro macOS inspirovaný
[Hyprlandem](https://hypr.land): okna se sama skládají vedle sebe a všechno
řídí jediná klávesa — CapsLock jako *hyper*.

![ancre tiluje celou plochu: dwindle layout se čtyřmi okny a workspace barem](../../../assets/hero-desktop.png)
*/}

*Tiling neznáš?* Místo vršení oken na sebe dá tiling window manager každému
oknu vlastní slot v layoutu a využije celou obrazovku. Přepínáš se mezi
číslovanými **workspaces** (virtuálními plochami) a fokus ovládáš
klávesnicí.

- **Layouty** — dwindle (spirálové dělení jako v Hyprlandu), sloupce
  („scroll”), stack (jedno okno naráz), vlastní layouty ze šablon v configu
- **Workspaces 1–9** napříč monitory se stabilním přiřazením (přežije replug)
- **Workspace bar** — ikonky oken, drag&drop, badge notifikací; pozice včetně
  menubaru a notche
- **Hyper klávesa** (CapsLock) pro všechny zkratky + myší módy (hyper+drag)
- **AI ready** — `ancrectl` CLI, unix socket, vestavěný MCP server, Claude
  skill: agent přeuspořádá celý setup jedním voláním
- **Nativní a bezpečné** — čisté veřejné Accessibility API, žádný zásah do
  SIP, žádné kernel extensions ([detaily](/ancre/cs/architecture/))

## Rychlý start

```sh
brew tap wraithyy/tap
brew trust wraithyy/tap          # third-party tap potřebuje jednorázový trust
brew install --cask ancre
open /Applications/ancre.app
```

Preferuješ build ze zdrojů? Viz [Instalace](/ancre/cs/installation/).

První spuštění zobrazí onboarding okno, které tě provede dvěma potřebnými
permissions (**Accessibility**, **Input Monitoring**). Pak:

```sh
hyper+1..9        # přepnutí workspace   (hyper = CapsLock)
hyper+h/j/k/l     # fokus směrem
hyper+t           # scroll layout
ancrectl state    # JSON snapshot monitorů, workspaces a oken
```

Podržení hyperu 2 s zobrazí celý [cheatsheet zkratek](/ancre/cs/controls/).

## Známá omezení

- Offscreen parking (skrývání oken neaktivních workspaces) spoléhá na to,
  jak macOS clampuje AX pozice oken u okraje obrazovky — chování, které se
  liší podle verze macOS.
- Animace se automaticky vypnou pro appky, jejichž AX odpovědi jsou příliš
  pomalé na plynulou animaci.
- Žádná distribuce přes App Store: ancre potřebuje Accessibility přístup
  a přemapovává CapsLock přes `hidutil`, obojí mimo App Store sandbox.
- App je ad-hoc podepsaná, ne notarizovaná — Gatekeeper je spokojený díky
  Homebrew casku (nebo ručnímu sundání quarantine při buildu ze zdrojů), ale
  Apple notarization ticket chybí.
- Jedna zdokumentovaná výjimka z „čistě veřejného API”:
  `_AXUIElementGetWindow` přes `dlsym`, použité k získání stabilního
  `CGWindowID` z `AXUIElement` (stejný trik používá yabai i Amethyst);
  degraduje elegantně, kdyby symbol někdy zmizel.
