ancre

A tiling window manager for macOS power users. Keep windows moving around a fixed point: the task in front of you.

Quick start Configure

Layouts

Use predictable tiling modes for coding, browsing, terminal work, and mixed-focus sessions.

ancrectl layout dwindle
ancrectl focus east
ancrectl move west

Commands

Expose every action through a small command surface that can be bound to keyboard shortcuts or scripts.

ancrectl windows
ancrectl workspace 2
ancrectl reload

Configuration

Keep configuration readable. Defaults should be useful, overrides should be explicit.

[layouts]
default = "dwindle"

[gaps]
inner = 8
outer = 10
